# Elevator Management System

A Low-Level Design (LLD) implementation of an Elevator Management System using Java and Spring Boot.

## Features

- Request an elevator based on current floor and direction
- Select a suitable available elevator
- Add destinations to elevators
- Track elevator current floor and status
- Release elevators after completing a request
- REST APIs for elevator operations

## Tech Stack

- Java
- Spring Boot
- REST APIs
- Object-Oriented Design
